Триггер Т0 - начальная точка отсчета времени
Порог обнаружения - линия< определяющая случайны шум от реальной вспышки.
Окно поиска - это фиксированный временной интервал вокруг радиовсплеска, внутри которого ищем гамма-засвет. Оно показывает, совпал ли главный пик с радиовсплеском (длинна окна 11 бинов+-1 из-за погрешности)
Пока что R=1*

Работа приложения
1) перевод координат галактических в экваториальные
2) Отбираем фотоны возле окрестности
окно поиска = +-7 минут, окно исключения фотона +-1,2 часа
3)бинирование/Разбитие ряда по 0.001 дня/86.4 с и считаем колицество фотонов в каждом бине
4)Оцениваем фон: Исключаем окрестность возле ТО(+-0.05 дня/4320 с); в оставшихся бинах считает среднее число отсчетов; mu_bg =среднее числа отсчетов на бин
5) Скользящая сумма: суммирует отсчеты в окне из 5 соседних бинов; ожидаемое число фотоновых отсчетов nu_bg *5 - >растет чувствительность
6)  Расчёт pre trial p value: определяет вероятность того, что фон с пуассоновским распределением даст >наблюдаемого числа отсчетов(вероятность флуктуации фона)
7) Look-elsewhere effect. Эффективное число независимых испытаний
8) Post-trial p-value - итоговая оиченная вероятность

8) порог обранужения: pre trial = 5сигма, post trial зависит от кол-во попыток  
9) Построение графиков
10) вывод:Время лучшего бина, Pre trial p value и значимость;Post trial p value и значимость;смещение пика от Т0; статус обнаружения
